What the score means

Removed from the main ranking

The leaderboard uses the latest comparable results for each benchmark. Each benchmark has equal weight, with repeats averaged. Scores use only benchmarks completed by every model with matching repeats and verified replays. Coverage is shown beside the score. Pending attempts and infrastructure errors remain visible and are not failures. Tokens include all selected attempts, including unscored tasks.

The combined score is exploratory because tool versions differ across tasks. Each task records its source comparison, version and replay. Pilot results are available inside each benchmark. Full historical archives remain local. A clean controlled comparison would rerun all models on one frozen version. One attempt per task does not establish reliability.
