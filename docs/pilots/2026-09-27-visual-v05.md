# Visual feedback pilot with Luna and Terra

Both user-authorized runs used the same verified starter checkpoint, low reasoning
effort, the visual track, and a 500,000 reported-token threshold per model. The
protocol was `red-v0.5-experimental`, harness `codex-cli-visual-feedback-v3`.
See [the protocol](../visual-feedback-v05.md) for all observation and budget rules.

Each model received enlarged before/after screen strips, exact controller timing,
pixel-change measurements, and its own structured notebook. No RAM game facts,
route guidance, or evaluator flags were supplied. Decisions allowed two actions.
There were no retries, human gameplay interventions, paid API fallbacks, or reset
credit redemptions. The controller-reference check ran separately without a model.

## Interpretation

Luna repeatedly treated the lower-left furniture as an exit. Its notes recorded
failed moves but continued proposing similar actions. On some decisions, its
stated next experiment differed from the issued input. At decision 55, the saved
input strip visibly showed the bedroom while the model described an outdoor
scene. The notebook later revised that claim but did not resolve navigation.

Terra initially repeated the lower-left route, then traversed the room and
reached the ground floor. Its decision 26 notes correctly identified downstairs,
but it continued issuing inputs around the staircase and returned upstairs.
It chose one explicit wait. Luna chose five. No automatic settling or navigation
was added. Terra never reached map 0 and finished upstairs.

Neither model improved its task outcome. Compared with the earlier structured
500k trials, average reported input per decision rose from 4,332.25 to 5,171.51
for Luna and from 5,794.58 to 6,567.69 for Terra. Their call counts fell from 112
to 91 and from 83 to 72. Executed actions fell from 244 to 139 and from 238 to 98.
The smaller batch limit, image strip, different prompt, different observations,
and notebook all changed together, so these differences are descriptive rather
than estimates of a single feature's effect.

This combined intervention changes imagery, memory, prompt, batch length, and
access to structured facts at once. These single trials cannot identify the
effect of an individual change or establish a reliable model ranking. Larger
visual context and structured notes also have a token cost.

Raw model responses, images, states, and ROMs remain local under the run folders.
Sanitized outcomes and artifact hashes are frozen in the manuscript export.
