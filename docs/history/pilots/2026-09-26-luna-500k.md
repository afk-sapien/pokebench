# Luna starter trial with a 500,000-token budget

The user requested one new Luna run with a 500,000-token budget. The run used
`gpt-5.6-luna`, low reasoning effort, and the ChatGPT subscription through Codex
CLI 0.147.0. It started from the same verified bedroom checkpoint as the earlier
30,000-token starter trials, with the same structured observations, original
160 by 144 screenshot, gameplay prompt, and no name-label table.

## Outcome

Luna did not leave the bedroom or obtain a starter. Score was 0/1. Its notes
repeatedly identified the lower-left area as an exit and continued trying that
area despite observing no map transition. Every recorded post-action map was
the starting bedroom, map 38. The final party was empty.

| Measure | Result |
| --- | ---: |
| Reported input tokens | 485,212 |
| Reported output tokens | 14,190 |
| Total reported tokens | 499,402 |
| Model decisions | 112 |
| Executed controller actions | 244 |
| Emulator frames | 6,155 |
| Emulated seconds | 103.05 |
| Wall seconds | 584.05 |

The run stopped because the remaining token budget could not cover the next
estimated decision. Accounting was complete for every call. No second attempt,
manual gameplay guidance, paid API fallback, or usage-reset credit was used.
The reported-token threshold is enforced between decisions with a reserve,
not as a provider-side hard cap.

Secondary limits were 150 model calls, 1,200 controller actions, 360,000 emulator
frames, and 3,600 wall seconds. Each action allowed at most 600 frames and each
decision at most eight actions. None of these secondary limits ended the run.
The scenario and runtime protocol remained `red-v0.4-experimental` with harness
`codex-cli-cooperative-v2`. Changed limits create a separate comparison group.

## Verification and provenance

All 244 controller actions passed deterministic replay, including frame counts,
screenshots, private evaluator evidence, score, and trace hashes. Every action
remained on map 38. The local run is `runs/starter-v04-luna-500k-01`, and its
`verification.json` records the successful replay. The trace head is
`25049b572b189f505ac59915a15351eae663f1980f604a67b26baccf78b9e8e8`.

The start was `scenarios/starter-repro-v04`, curated from
`fixtures/opening-starter-v1.json`. Its successful controller reference was not
provided to the model. The run manifest pins the model, instructions, source,
core, ROM, checkpoint, image, limits, CLI, and reasoning settings. Sanitized
outcomes and artifact checksums are recorded in the paper input export. Raw
responses, screenshots, ROMs, and emulator states remain local.

This trial establishes a failed starter attempt under this configuration. It
does not establish that Luna cannot complete the task with other observations,
instructions, or sampling outcomes. Increasing the budget alone did not rescue
this attempt. Screen interpretation and repeated unsuccessful actions remain
useful targets for the next harness investigation.
