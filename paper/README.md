# PokeBench technical report

Built with [Paper Scaffold](https://github.com/pgarrett-scripps/paper-scaffold)
5.3.2, pinned to `c9cb1046d710b3fab851e9984b23254b82a031bc`.
The upstream MIT notice remains in `LICENSE.scaffold`.

The current report covers the completed focused pass: six models, 48 task
entries, 47 score groups, 50 registered starts per model, and 300 attempts.
It includes a failure audit and a separately reported matched repeat check.
The current repeat count is generated from the analysis snapshot rather than
maintained in this README. PokeBench Long is outside this comparison.

The prior manuscript is preserved in `archive/focused-pre-v060`. Older analysis
inputs remain available for historical work. The earlier prospective protocol
is an archived plan, not the coverage or spending limit of this focused pass.

## Refresh the data

From the benchmark repository, supply your private run and website directories:

```bash
uv run python scripts/export_focused_analysis.py \
  --run /path/to/focused-pass-v056 \
  --web /path/to/local-preview \
  --repeats /path/to/stability-v060 \
  --paper-input paper/analysis/inputs/focused-v060.json
```

This writes a field-selected summary. It does not copy ROMs, saves, screenshots,
model transcripts, credentials, or private directory paths into the report.
It does not run models or publish the website. Gameplay replay links are local
paths relative to the preview directory.

## Rebuild

From this manuscript directory:

```bash
uv sync --locked
uv run paper sync --check
just assets
just fmt
just paper
just verify
```

`paper.pdf` is the report. Numeric prose uses scaffold statistic IDs. Tables are
generated by the analysis scripts. Earlier declarations remain available for
archived reports and may generate unused-declaration warnings.

## Optional source staging

`export_public.py` copies an explicit allowlist into a new or empty directory.
It never publishes. It retains the pinned scaffold, license, source manuscript,
analysis inputs, generators, tables, and compiled report. Archives and private
run artifacts stay excluded.

```bash
uv run python export_public.py --output /tmp/pokebench-paper-source
```

`PUBLIC-FILES.json` records copied file hashes. Rebuild before staging. A source
package alone does not include privately served gameplay replays.
